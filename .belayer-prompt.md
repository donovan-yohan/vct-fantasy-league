## Task Specification

# VCT Fantasy League Web Application

## Objective

Build a fantasy league web application for Valorant Champions Tour (VCT) esports. Users create fantasy teams by drafting pro players via auction with salary cap, earn points based on real match performance, and compete on a total points leaderboard. The app covers all VCT regions and tournaments with the ability to reset for international events.

## Data Source

Uses https://github.com/axsddlr/vlrggapi (hosted at vlrggapi.vercel.app) as the data source.

- REST API, no auth required, 600 req/min rate limit
- Endpoints: `/v2/stats`, `/v2/player`, `/v2/match/details`, `/v2/team`, `/v2/events`, `/v2/events/matches`
- Available stats: ACS, K/D/A, KAST%, ADR, KPR, APR, FKPR, FDPR, HS%, clutch%, multi-kills (2K-5K), plants, defuses, Rating 2.0
- Limitations: no search-by-name, no structured brackets, need vlr.gg numeric IDs, no real-time websocket updates

## Requirements

### Fantasy Mechanics
- **Roster**: 5 positional slots (Duelist, Initiator, Controller, Sentinel, IGL) + 1 wildcard = 6 players
- **Draft**: Auction with salary cap
- **Scoring**: Combat performance-weighted (not just kills). Balanced across roles so Duelists don't always dominate. Configurable formula. Reference DraftKings scoring as baseline (Kill +2, Assist +1, Combat Score +0.02/pt, clutch/multi-kill bonuses)
- **Competition**: Total points leaderboard, resettable per international event
- **Team limits**: Max 2 players from any single real team
- **Captain**: Star player multiplier
- **Eliminated teams**: Waiver/replacement mechanic when a player's real team is eliminated
- **Scope**: All VCT regions (Americas, EMEA, Pacific) and tournaments (Kickoff, Masters, League Stages, Champions)

### Tech Stack
- **Frontend**: TanStack Start + TanStack Query + TypeScript
- **Auth**: Google/Discord sign-in via free-tier provider
- **Backend**: Simple backend for persisting user fantasy teams, league state, scoring calculations

### Design
- Valorant-themed, reverse-engineered from public visual identity
- Colors: Red #FF4655, Dark BG #0F1923 / #1A242E, Off-white text #ECE8E1, Dark red #BD3944
- Fonts: Tungsten Bold (headlines), DIN Next (UI), Montserrat (body)
- Style: Angular/geometric shapes, high-contrast, dark-dominant, military-precision aesthetic

### Pages
- Dashboard/home with live scores and standings
- Team builder/draft interface (auction)
- Player browser with stats and filters
- Matchday view with live scoring
- League standings and head-to-head
- Player detail pages with historical stats
- Settings/league management

## Acceptance Criteria
- Users can sign in with Google or Discord
- Users can create/join a league
- Users can draft a 6-player fantasy team via auction with salary cap
- Fantasy points are calculated from real VCT match data via vlrggapi
- Scoring formula is configurable and balanced across roles
- Leaderboard tracks total points with reset capability
- Waiver system handles eliminated team replacements
- UI follows Valorant design language
- App handles vlrggapi rate limits gracefully with caching
